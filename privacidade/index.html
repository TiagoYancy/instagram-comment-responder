Política de Privacidade

Última atualização: 01 de outubro de 2026

1. Informações que Coletamos

Este aplicativo coleta apenas os dados necessários para responder comentários no Instagram de forma automatizada:

  • ID da conta do Instagram
  • Comentários públicos em posts
  • Respostas enviadas pela conta

2. Como Usamos os Dados

Os dados coletados são utilizados exclusivamente para:

  • Responder comentários em nome da conta do Instagram
  • Melhorar a qualidade das respostas
  • Prevenir spam e abuso

3. Compartilhamento de Dados

Não compartilhamos dados pessoais com terceiros. Todas as informações são processadas localmente e não são vendidas, alugadas ou transferidas.

4. Armazenamento de Dados

Os dados são armazenados de forma segura e mantidos apenas pelo tempo necessário para a operação do serviço. Não retemos dados indefinidamente.

5. Segurança

Implementamos medidas de segurança para proteger suas informações contra acesso não autorizado, alteração, divulgação ou destruição.

6. Seus Direitos

Você pode solicitar a exclusão dos seus dados a qualquer momento entrando em contato conosco.

7. Contato

Para dúvidas sobre esta política, entre em contato:

  • Site: yancy-it.com

8. Alterações nesta Política

Podemos atualizar esta política periodicamente. A data de última atualização será revisada conforme necessário.
